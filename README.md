# پارس — سرمایه‌گذاری جسورانه

نمونه‌ی رابط فارسی و راست‌چین برای سایت شرکت سرمایه‌گذاری «پارس». صفحه‌ی اصلی شامل رویکرد سرمایه‌گذاری، هشت حوزه، مزیت‌های همراهی، پرتفوی نمونه، ابزارهای تعاملی، مرکز دانش، همکاران، مجوزها و تماس است. صفحه‌ی کمپین و فرم چهارمرحله‌ای از `#apply` در دسترس است و برای میزبانی روی زیردامنه‌ی `apply.` نیز مسیر اولیه در نظر گرفته شده است.

## اجرا در محیط توسعه

```bash
npm install
npm run dev
```

برای اجرای هم‌زمان سایت و API محلی:

```bash
cp .env.example .env
# در .env نام کاربری و گذرواژه‌ی شخصی مدیر (حداقل ۱۶ نویسه) را تنظیم کنید
npm run dev:full
```

در این حالت سایت روی Vite اجرا می‌شود و درخواست‌های `/api` از طریق proxy توسعه به سرور Node می‌رسند. هرگز فایل `.env` را commit نکنید.

ساخت نسخه‌ی production:

```bash
npm run build
```

## انتشار

GitHub Pages روی شاخه‌ی `arena/4d1d0891-website` و پوشه‌ی ریشه تنظیم شده است. گردش‌کار GitHub Actions فایل‌های Vite را می‌سازد و فرانت‌اند ایستا را منتشر می‌کند؛ Pages API، ورود مدیر یا ذخیره‌سازی پایدار اجرا نمی‌کند.

برای انتشار کامل فرانت‌اند و بک‌اند روی دامنه‌ی خودتان، بسته‌ی Docker Compose، health check، volume پایدار SQLite/PDF و Caddy با HTTPS خودکار آماده است. مراحل نصب سرور، تنظیم دامنه و secretهای لازم در [`DEPLOY.md`](DEPLOY.md) آمده است. این روش به VPS/سرور Docker و مقادیر واقعی مدیر نیاز دارد؛ این اطلاعات عمداً در مخزن قرار ندارند.

## وضعیت داده‌ها و سامانه‌ها

- فونت فارسی Estedad Variable به‌صورت محلی بسته‌بندی شده؛ سایت برای نمایش متن به سرویس فونت خارجی وابسته نیست.
- هیروی پارس یک کریستال بیست‌وجهی برداری است که با SVG سبک، انیمیشن و واکنش به نشانگر ساخته شده؛ کتابخانه‌ی سه‌بعدی یا تصویر رستری بارگذاری نمی‌شود و حرکت آن بیرون از محدوده‌ی دید متوقف می‌شود.
- مسیر مرزی ایران از بسته‌ی `@svg-maps/world` (اثر Victor Cazanave، مجوز CC BY 4.0) استخراج و به‌صورت SVG درون‌خطی نمایش داده می‌شود. نام و نقطه‌های شهرها فقط جانمایی نمایشی‌اند و حضور شرکت را نشان نمی‌دهند.
- هشت محاسبه‌گر در مرورگر اجرا می‌شوند و داده‌ی ورودی را به سرور نمی‌فرستند.
- فرم درخواست و فرم تماس به API واقعی `/api` متصل‌اند. پاسخ موفق تنها پس از ثبت تراکنشی در SQLite اعلام می‌شود؛ فایل PDF (حداکثر ۲۰ مگابایت) خصوصی نگه‌داری و فقط در پنل احراز هویت‌شده قابل دریافت است.
- پنل خصوصی در مسیر `#admin` قرار دارد؛ حساب پیش‌فرض ساخته نمی‌شود. نام کاربری و گذرواژه‌ی مدیر باید با متغیرهای محیطی سرور تنظیم شوند. نشست، محافظت CSRF، محدودسازی تلاش ورود، وضعیت‌دهی/یادداشت و حذف اطلاعات در API پیاده‌سازی شده‌اند.
- اعلان‌های فرم از صف پایدار ایمیل استفاده می‌کنند. تحویل ایمیل فقط وقتی فعال است که نشانی مقصد، فرستنده‌ی تأییدشده و کلید Resend در سرور پیکربندی شوند؛ در غیر این صورت داده در پایگاه داده ثبت می‌شود و وضعیت اعلان «پیکربندی‌نشده» است.
- SQLite از `node:sqlite` داخلی Node 22 استفاده می‌کند؛ این API در Node 22 هنوز Experimental است. محدودیت runtime، durability و مسیر مهاجرت در `BACKEND_PLAN.md` آمده است.
- GitHub Pages فقط فایل‌های ایستا را اجرا می‌کند و API یا پایگاه داده ندارد. روی دامنه‌ی Pages بدون `PARS_API_BASE_URL` فرم‌ها صریحاً اعلام می‌کنند که داده ارسال نشده است. برای جزئیات معماری و انتشار، `BACKEND_PLAN.md` را ببینید.
- ورود متقاضی با کد یک‌بارمصرف/پیامک هنوز فعال نیست؛ سرویس پیامک و جریان خودخدمت متقاضیان تا زمان انتخاب و پیکربندی ارائه‌دهنده عمداً غیرفعال‌اند.
- نام شرکت، آمار سرمایه‌گذاری، شهرها، مبلغ و شرایط دوره، اطلاعات تماس، مجوزها، شرکا، اعضای تیم و محتوای پرتفوی باید با اطلاعات رسمی شرکت جایگزین شوند؛ داده‌ی رسمی یا اعتبارنامه‌ای در این مخزن ساخته نشده است.
